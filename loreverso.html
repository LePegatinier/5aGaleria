Laboratorio científico, filosófico y experimental del Loreverso Pegatinier.

Una sola dimensión. El resto son capas.

El PGTNR_LAB investiga aquello que sucede cuando una pegatina deja de ser solamente una pegatina.

Materia. Muro. Memoria. Desgaste. Accidente. Autoría. Archivo. Tiempo.

Aquí se estudia la continuidad entre cosas que normalmente consideramos separadas: interior / exterior · obra / soporte · autor / consecuencia · organismo / entorno · original / copia · error / información · desaparición / memoria.

Porque quizá no sean cosas distintas. Quizá sean capas.

01 / MODELO CONCEPTUAL

CINTA DE MÖBIUS

El laboratorio trabaja con una hipótesis: la realidad puede entenderse como una continuidad que percibimos como capas.
