# Archivo público — 5a Galeria

Este directorio contiene los datos publicados del archivo de la 5a Galeria.

`archivo.json` se genera y sincroniza automáticamente desde el Archivo Maestro de Notion mediante GitHub Actions.

Los expedientes de prueba anteriores han sido retirados del archivo público. El archivo queda limpio y preparado para recibir avistamientos reales.
