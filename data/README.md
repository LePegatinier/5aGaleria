# ARCHIVO PÚBLICO 5a GALERIA

`archivo.json` es la frontera editorial entre el Archivo Maestro de Notion y la web pública.

Sólo deben entrar aquí expedientes autorizados para publicación.

## Esquema

```json
{
  "version": "0.1",
  "source": "5a GALERIA / ARCHIVO MAESTRO",
  "updated": "YYYY-MM-DD",
  "records": [
    {
      "expediente": "5a-000001",
      "titulo": "Descripción o título editorial",
      "artista": "ANÓNIMO",
      "ciudad": "Barcelona",
      "ubicacion": "Barrio / ubicación general",
      "coordenadas": "41.3851, 2.1734",
      "fecha": "2026-09-07",
      "tecnica": "Sticker",
      "estado": "En la calle",
      "stratascore": "A — STREET RAW CERTIFIED",
      "imagen": "https://...",
      "publicado": true,
      "url": "expediente.html?id=5a-000001"
    }
  ]
}
```

No se deben incluir aquí datos privados, nombres civiles no autorizados, información interna de revisión ni originales sensibles.
